# 美化与功能改造指南（Hugo + Stack）

> 写于 2026-10-31，基于当前线上版本实测。原则：**永远不改 `themes/` 里的文件**——复制一份同名文件到项目里覆盖，升级主题时才不会被冲掉。

## 0. 三条安全线

| 你要改的 | 改哪里 | 为什么 |
|---|---|---|
| 样式（颜色/字体/间距/圆角） | 项目新建 `assets/scss/custom.scss` | 主题的 `style.scss` 最后一行就是 `@import "custom.scss"`，你的样式天然排在最后、优先级够 |
| 结构（模板/局部） | 把主题同名文件复制到项目 `layouts/` 相同路径再改 | Hugo 的模板查找顺序里项目优先于主题 |
| 开关（头像/评论/字重/行号） | `config/_default/params.toml` | 能配置就别写代码 |

主题自带的扩展钩子（不用复制文件就能加东西）：`layouts/_partials/head/custom.html`（往 `<head>` 里塞任意内容）、`custom-font.html`（字体）。

## 1. 现在实测的短板

| 问题 | 证据 |
|---|---|
| **还在拉 Google Fonts** | `head/custom-font.html` 硬编码 `fonts.googleapis.com` 的 Lato——全站唯一的境外依赖，比旧站干净但没干净透 |
| 没有头像、没有 favicon | `params.toml` 里 `sidebar.avatar` / `favicon` 为空 |
| 没有评论、没有访问统计 | `[comments] enabled = false` |
| 首页只有一张文章卡 | 没有个人名片/hero，新访客不知道你是谁 |
| 页脚只有一行版权 | 没有「订阅/RSS/许可协议」入口 |

已经自带、不用做的：代码块**复制按钮**（`code-copy.ts`）、GitHub 风格**提示块**（`> [!note]`）、**图集放大**（PhotoSwipe）、**导航目录**、**暗色模式**、**站内搜索**、Mermaid 图表。

## 4. 三档套餐

- **快修（约 1 小时）**：1 字体本地化 + 2 主色 + 3 头像/favicon + 5 卡片质感 + 6 代码配色
  → 观感变化最大、零风险，改完就能推。
- **定型（约 3 小时）**：快修 + 4 个人名片 + 评论 + 统计 + RSS 入口 + 友链页
  → 一个「像样的个人站」的完整配置。
- **折腾（按需）**：背景、进度条、分享、加密、OG 图、自定义短代码
  → 每项独立，想加再加。

## 5. 代码片段（可直接抄）

### 字体本地化（去掉 Google Fonts）

新建 `layouts/_partials/head/custom-font.html`，内容留空或只写注释即可——**同名文件覆盖就是「关掉」**。然后在 `assets/scss/custom.scss` 里指定字体：

```scss
:root {
  // 中文优先：系统字体栈，零下载、零外链
  --base-font-family: -apple-system, BlinkMacSystemFont, "PingFang SC",
    "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans SC", sans-serif;
  --article-font-family: var(--base-font-family);
  --code-font-family: "JetBrains Mono", Menlo, Monaco, Consolas, monospace;
}
```

想用霞鹜文楷：把 `LXGWWenKai-Regular.woff2` 丢进 `static/fonts/`，再：

```scss
@font-face {
  font-family: "LXGW WenKai";
  src: url("/fonts/LXGWWenKai-Regular.woff2") format("woff2");
  font-display: swap;
}
:root { --article-font-family: "LXGW WenKai", var(--base-font-family); }
```

### 主色与卡片质感

```scss
:root {
  --accent-color: #2f6f6a;          // 主色（链接、标签、按钮）
  --card-border-radius: 14px;
  --card-shadow: 0 4px 24px rgba(0, 0, 0, 0.04);
}
.article-list--compact article:hover,
.article-card:hover { transform: translateY(-2px); transition: transform .2s ease; }
```

（深色模式的变量在 `body.dark` 作用域里，同样可以覆盖。）

### 评论（giscus）

```toml
[comments]
    enabled  = true
    provider = "giscus"

    [comments.giscus]
        repo     = "KaiTeeDreamChai/KaiTeeDreamChai.github.io"
        repoID   = "R_xxx"          # 仓库 Settings 页可查
        category = "Announcements"
        categoryID = "DIC_xxx"
        mapping  = "pathname"
        lang     = "zh-CN"
```

前提：仓库开 Discussions，装 giscus app。

## 6. 需要你提供的东西

| 做哪项 | 我需要 |
|---|---|
| 头像 / favicon | 一张图（≥ 256px），favicon 可以是同一张 |
| 评论 | giscus 的 repoID / categoryID（我可以带你走一遍，或你给我截图） |

| 配色 | 一个你喜欢的颜色，或说「你来定」 |

## 7. 我的建议

先做**快修套餐**：它改的全是样式层，零风险、不碰内容、随时可回退（一个 commit），而且能立刻看出「这个站是有人打理的」。做完你看效果，再决定要不要上评论和名片。

折腾方向我偏向：**字体和配色 > 个人名片 > 评论 > 其他**。理由是前两项每天都被看到，评论对 0 浏览的站暂时没收益。
